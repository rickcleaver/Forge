# Forge

Gym log for Android. Sessions, programs, muscle maps, coach chat, and Spotter for coaches.

Live site: https://forgelog.ca

Package id: `ca.forge.log`

## What’s new (best-in-class UX)

- **First-run onboarding** — goal, days, place → week plan + Next Move (existing logs stay setup-done).
- **Today-first Home** — one hero Start/Resume, quieter secondary, Programs entry.
- **Logging delight** — set-complete pop, rest theatre, PR flash with zero extra taps.
- **Programs hub** — `/programs` for yours / public / Spotter without crowding the tab bar.
- **Progress charts** — weekly volume, bodyweight trend, muscle balance + Muscles sub-nav + outcome loop.
- **Circles** — opt-in buddy codes (not a social feed).
- **Forge Sync MVP** — opt-in encrypted export/import; local-first remains default.
- **Health Connect** — clearer bridge negotiation for steps/sleep/readiness (no fake data).
